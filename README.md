# SpinnyStar

SpinnyStar is a modular stellar angular momentum evolution model that supports two-zone and three-zone formulations. 
The code is designed to facilitate testing of different physical prescriptions for angular momentum transport and loss.

## Installation

SpinnyStar requires Python 3.x. To install, first clone this repository and change into the `SpinnyStar` directory.

```bash
git clone https://github.com/ElijahBlesch/SpinnyStar.git
cd SpinnyStar
```

Install SpinnyStar in editable mode:

```bash
pip install -e .
```

The `-e` option is necessary so that updates or changes to the SpinnyStar source code are available without reinstalling the package.
